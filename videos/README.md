# Music videos

Put your own video files in this folder (for example `ditto.mp4`) and list them in `videos.json`:

```json
[
  { "title": "Ditto", "file": "videos/ditto.mp4" },
  { "title": "How Sweet", "youtube": "https://youtu.be/XXXXXXXXXXX" }
]
```

`file` plays your own copy, `youtube` embeds the official upload. Each entry becomes a button in the Music video theatre on the home page.
