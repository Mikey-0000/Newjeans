# Your lyric files (private use)

Put timed lyric files here, named after the song key: `ditto.lrc`, `hypeboy.lrc`, ...
Format (LRC): one line per lyric, each starting with a `[minutes:seconds.hundredths]` timestamp:

    [00:12.50]your first lyric line
    [00:16.20]your second lyric line

You don't have to write the timestamps by hand: on the home page open the CD shelf,
click a CD, press "Lyric lab", paste lyrics you own, and tap along to the song.
It saves in your browser and can export a `.lrc` file to drop in this folder.
